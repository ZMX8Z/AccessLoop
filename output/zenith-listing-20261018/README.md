## 素材来源与状态

- 图标复用当前前端 `public/stitch/app.js` 的 `accessible_forward` SVG 路径。
- 封面沿用前端深青、薄荷绿、浅色背景，以及 `public/stitch/campus.svg` 和路线图形，另行排版为品牌介绍封面。
- 封面中的地图是现有设计示意图，已保留 `DESIGN PREVIEW` 标记；不将其称为当前运行页面截图、现场核验数据或真实导航结果。
- `accessloop-app-icon.svg` 与 `accessloop-cover.svg` 是可编辑源文件。`build-assets.mjs` 使用项目已有的 sharp 导出位图，不改变应用代码。
- imagegen 生成试稿在本地导出复核中缺少前景符号，未用于最终上传文件。
- 当前运行前端的截图尚未取得：自动审批拒绝访问 `http://localhost:3121`，等待用户授予仅查看公众页面和截图的明确范围。不读取或导出 Cookie、浏览器存储、令牌或后台私人数据。
