# AccessLoop 权威文档索引

四个工作包共用本目录中的文档，AI 读取此索引后按任务查看对应正文。工作包文件夹只存放职责、启动词与验收材料，不维护另一套公共规则。

## 各类约定的唯一入口

| 文档 | 负责的事实 | 何时读取 |
| --- | --- | --- |
| [PROJECT.md](PROJECT.md) | 已确认范围、GLM、匿名会话、区域语言、个人/公共业务规则 | 开始任何工作包；判断业务状态或默认值 |
| [API_CONTRACTS.md](API_CONTRACTS.md) | HTTP 路径、字段、枚举、权限、错误、版本、幂等及示例 | 编写前后端接口、fixture、共享 Schema 和联调 |

| [ACCEPTANCE.md](ACCEPTANCE.md) | AI/人工验收边界、结果/证据格式及全项目追踪表 | 自检、独立验收和总集成 |

## 一致性与维护

- 共同产品决定放 PROJECT，字段定义放 API，分支/职责放 COLLABORATION，验收政策放 ACCEPTANCE；其他文档通过链接引用。
- D 整合共同文档；C 维护数据/报告/AI/管理接口，D 维护路线/地点/通道/搜索接口，A/B 检查消费方式。
- 运行时 Schema 和类型落实 API 契约。发现文档/代码分歧，由所属负责人明确修正，并同步 Schema、fixture 和调用方；不让各包自行选择一份作为临时协议。
- 需求和架构可保留解释及追踪，不复制另一套完整 HTTP 字段表。外部资料是能力参考，不能覆盖本项目已确认的范围和业务规则。
