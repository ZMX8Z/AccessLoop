# AccessLoop 项目决定与业务规则

版本 1.0，2026-10-17。本文记录四人开发已经确认的共同决定及业务规则。完整功能清单见[需求文档](AccessLoop_需求文档_v1.0.md)，HTTP 字段以[统一 API 契约](API_CONTRACTS.md)为准，分工和分支以[协作规则](COLLABORATION.md)为准。

## 交付范围

四个工作包必须完成全部 P0 与 P1。P0 完成只代表阶段完成，随后继续 P1；P2 不在本轮范围。本文是待实现的共同决定，不表示产品已上线或通过验收。

## 已确认决定

- 四人固定为 A/B 两名前端、C/D 两名后端。A 是当前使用 Stitch 搭建页面的成员。
- Stitch 以可导出页面代码交接，由 A 迁入同一个 Next.js 应用，B 沿用其视觉和公共组件。
- 用户界面、错误提示和报告使用英文；开发交接与验收说明使用中文。本轮不做语言切换。
- 演示区域为 UNSW Kensington 校园内一个经过实测的小区域，固定起终点和备选通道由 D 选定并交接。
- 支持本次路线片段和预设通道两种选择方式。选择通道后自动显示后端生成的避让范围，用户明确确认才生效。
- 匿名身份使用 HttpOnly、SameSite 会话 Cookie，生产环境启用 Secure；不设置持久化的 Expires/Max-Age。刷新页面保留身份，关闭浏览器后不承诺找回，不做跨设备恢复。应用重启不更换会话密钥。
- 个人避让默认从确认的观察时间起有效 3600 秒，公共核实默认有效 86400 秒，均可配置。过期不表示障碍已消失。
- 默认 VISION_PROVIDER=glm，VISION_MODEL=glm-4.6v-flash；使用服务端 VISION_API_KEY，具体模型及账号权限在真实调用时验证。
- GLM 使用原生图片输入和带 Schema 的工具参数提取结果，服务端再次执行结构与语义校验；不将供应商原生严格 Schema 保证作为验收前提。无有效工具结果、结构错误、拒绝和超时均进入明确降级。
- 个人流程无需管理员；公共发布、纠错、驳回和解除必须鉴权。公共发布不会自动公开原图或全部 AI 证据。
- P2 的完整公众账号、社区投票、自动市政提交、全城覆盖及完整监控平台不在本次范围。

GLM 方案依据已核对的[视觉模型说明](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash)与[对话接口说明](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)。C 实施时验证实际账号能力，不要求前端持有模型密钥。

## 公共管理与区域配置

- 管理动作使用 action=verify/correct/reject/resolve/reopen，操作者由服务端管理身份确定；已有报告写入携带 expectedVersion、幂等键和理由。
- verify 支持 pending/ai_assessed → verified，以及 verified → verified 的重新核实；验证独立证据、合法公共几何和有效期。AI 自评或一次用户确认不能代替独立证据。
- correct 修正事实或公共范围，不覆盖原始 AI；公共几何/核实依据变化时重新校验，需保留公共核实所需证据。
- reject 停止该报告避让并保留理由；resolve 仅用于已核实公共障碍的有证据解除；reopen 将 resolved/rejected 恢复 pending，不恢复旧确认或公共生效。
- 公共披露和公共有效集采用管理员最后认可的发布快照及独立 publicRevision；个人 rowVersion、确认、续期或停用不改变公共快照/publicRevision，也不影响其他会话的公共摘要。公共修订与私人记录分开保存。
- 公共发布、纠错、解除及公共几何/有效期修正更新 hazard_version；使个人确认失效的管理动作在同事务停用相关个人避让，并更新其 personal_version。
- 管理更新未改变个人确认依据时，保持该确认的合法绑定；若照片、位置、通道或生命周期使其失效，则显式停用。确认版本绑定最终提交版本。
- 公共及个人自然过期按读取时有效集判断，客户端比较 activeDigest，不依赖后台任务准时执行。
- C 持久化预设通道及其版本；运营者可配置当前区域的 bbox、预设通道、缓冲参数及演示标识。名称、时区等展示字段按需沿用模型。
- 区域配置经业务命令和 D 的验证保存。会使现有有效几何或确认失去合法性的修改返回配置冲突，引导先处理相关报告，不静默迁移。仅影响未来缓冲计算的修改不重写已确认几何，但使旧预览失效。
- 影响地理约束或有效集的合法配置修改更新相应上下文版本，D 丢弃旧路由/预览；展示配置不无条件增加全部个人版本。
- 审计须能展示操作者、动作、理由、时间及关联报告/配置版本；只保存 before/after hash 不满足后台展示需要。
- 管理账号至少区分纠错管理员与部署运营者：前者处理报告，后者还可配置区域。首个账号受控初始化，公众不能注册管理账号。
- 公共报告使用脱敏字段；本轮公共页面默认不披露原图。管理员和作者仍通过授权入口查看照片。

## 文档与接口变更

- 同一仓库只维护一套 authority 文档，四包引用它，不复制出包内 API 或业务规则版本。
- API 文档承载跨前后端字段契约，Schema 是该契约的可执行实现；发现差异先对齐所属负责人，再在同一阶段变更中同步文档、Schema、fixture 和调用方。
- 已有用户决定不因开发者个人偏好变更。确有产品含义变化时集中说明影响并向用户澄清，期间继续不依赖它的工作。
- 外部服务型号、权限、配额及部署能力按实际账号核验；未核验项保留阻塞标识，不把示例值或桩结果写成实际成果。
