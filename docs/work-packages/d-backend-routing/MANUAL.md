# 工作包 D：人工功能与界面检查

由 AI 先准备可访问页面、演示数据和必要测试账号，再由人工只点击页面、检查功能、界面和文案。技术验证及证据由 [AI 验收](ACCEPTANCE.md) 完成。

- [ ] 手机上从在线地址完成规划、真实照片识别、修正、预览确认、绕行及报告。
- [ ] 搜索地点并设置起终点，理解无结果和失败提示。
- [ ] 使用 AI 准备的管理/公众窗口完成公共核实发布、公众重算、纠错/解除。
- [ ] 后台六类内容均有可用入口，功能文案清楚。
- [ ] 按演示稿在约 120 秒内展示核心价值，能说明个人与公共影响的区别。

## 本机底图与设施补充验收

打开 http://localhost:3000/live，确认Demo标记和“routes not field validated”说明。检查底图道路/建筑显示及OSM署名；点设施标记设置起点，切换List点另一个设施设置终点，检查来源/许可、unknown和主源暂不可用提示。手机窄屏应可滚动操作，地图不挤出页面。演示通道明确synthetic，不能作为实测可通行依据；本项不要求点击Plan或重复付费API调用。
