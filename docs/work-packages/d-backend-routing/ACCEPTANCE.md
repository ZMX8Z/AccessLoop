请独立验收AccessLoop工作包D及集成版本，范围为完整P0和P1。

核对四包交接、代码和部署配置。实际运行必要命令及浏览器流程，不修改产品代码。可以使用隔离演示数据，并复用同集成提交可核对的 C 包证据。

先运行构建、类型检查及已有相关检查，再按场景验收：
1. P0：固定起终点和限制得到有效wheelchair路线；真实照片经GLM、修正、预览及明确确认后，本会话绕行或明确无路线，全程无管理员；另一会话不采用该个人报告。
2. 一致性：个人停用/过期、公共变化及迟到结果正确处理；缓存/进行中请求/routeRef隔离；10秒内提示相应变化，轮询不调用ORS。
3. 失败与预算：少量桩覆盖无路线、端点受阻、超区域、429、配额403、鉴权403和超时；预算原子预留且按服务分开，重试计量，失败不放宽限制。

8. 部署恢复：Zenith可访问，生产配置不泄露秘密；重启保留报告、授权图片、确认和预算，过期避让不复活；一次最小备份恢复成功。
