# 工作包 A：真实页面功能与界面检查

AI 已准备本机生产入口 [AccessLoop](http://localhost:3121/route)。Demo 指区域/通道未现场验证；地图、搜索、报告API为真实服务。人工只点页面，不运行命令或查库。原始六屏并排核对证据见[A验收](../../acceptance/wp-a.md)。

- [ ] 360px手机与桌面打开首页，首先看到品牌、地图、浮动搜索、紧凑路线面板和 Route / Report / My Reports；主操作可见，底部安全区不压住内容。
- [ ] 打开搜索，拒绝定位时用列表或坐标选点；能交换A/B、选择区域支持的参数；关闭面板回同一地图。
- [ ] 显式 Plan。成功时看真实距离/估计时长/来源；Start Journey进入同地图和实际参考节点。没有合法当前路线时不能开始；返回/结束保留输入。
- [ ] 上游失败或等待时输入仍在，能手工重试。拖图、切Tab和开关面板不自动重算。
- [ ] Report中相机/相册选自己的测试照片；外部AI同意默认未选，选择后才分析。也可明确人工继续。不要将合成验收照片作为现场证据。
- [ ] P2的分析结果/不确定/失败文案真实；修正类别、说明、实际观察时间、位置和预设/当前路线片段。保存后先看服务端范围，明确勾选后确认；仅保存须明确选择。
- [ ] P1/P2无底部Tab，返回/取消来源正确；取消回Route再进入Report，未完成草稿保留。换照片后旧分析/预览/同意失效。
- [ ] P3显示真实编号和实际个人/公共范围，Return to Route使旧路线过时；不出现假测量、派工或公共核实。已确认有效的本人P3刷新可恢复；乱输编号不能伪造成功。
- [ ] My Reports使用紧凑列表卡，完整编号进入详情可查；三筛选正确，过期不当成Resolved；详情后返回仍保留筛选。停用/重新确认、复制文本和授权打印均可用；停用个人避让不解除公共报告。
- [ ] 键盘焦点可见；面板内可滚到最底操作，Escape可关路线面板，Tab不逃出面板；地图、列表/坐标均可操作。主按钮和链接触控至少44px。
- [ ] 数据来源、许可、unknown、主设施源失败及非完整库存说明可从Layers查看。所有synthetic通道与未实测区域保持Demo标识。

实际GLM请求和后续ORS重算在本轮超时，故其真实成功应待供应商恢复后由AI准备场景；人工不负责技术诊断。原生系统打印预览、现场校园及Zenith仍分别待验。
