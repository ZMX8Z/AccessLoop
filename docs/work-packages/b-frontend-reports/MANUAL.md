# 工作包 B：人工功能与界面检查

由 AI 先准备可访问页面、演示数据和必要测试账号，再由人工只点击页面、检查功能、界面和文案。技术验证及证据由 [AI 验收](ACCEPTANCE.md) 完成。

- [ ] 上传、修正、预览确认、人工备用和个人停用均能通过页面完成。
- [ ] 报告编号、状态、有效期及复制打印内容清楚。
- [ ] 使用 AI 准备的管理员入口和账号查看照片、AI 与用户修改，完成公共核实及纠错/解除。
- [ ] 驳回、重开和重新核实的页面结果符合说明，错误提示保留输入。
- [ ] 审计可读；区域配置能保存；调用摘要有明确数据或无数据状态。

- [ ] 未先规划路线时可选择预设通道；From/To空控件不出现。选择实际观察点或应用区域内坐标、描述及实际时间后可保存；缺项提示明确。
- [ ] 修改经纬度后，点击Set report location才恢复保存；无效坐标有区域范围提示，不会保存旧位置。
